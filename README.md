# AI Start UP

学習コンテンツを整理するためのリンク集サイトです。

AIツール、開発スキル、Git、Mac操作など、作成済み・作成中の学習コンテンツを一覧で確認できるようにしています。各コンテンツは GitHub リポジトリで管理し、公開している教材は GitHub Pages へのリンクから閲覧できます。

## Site

[AI Start UP - Hands-on Library](https://akilab.github.io/learn/)

## Purpose

- 作成した学習コンテンツを一覧で管理する
- GitHub Pages で公開している教材へアクセスしやすくする
- 教材の状態やタグを整理し、今後の追加に備える

## Structure

- `index.html`: サイト本体
- `css/default.css`: Simple テーマのスタイル
- `css/firm.css`: Cute テーマの追加スタイル
- `js/script.js`: コンテンツ、タグ、状態、表示切替の管理
- `img/`: ロゴやヒーロー画像などの画像素材
